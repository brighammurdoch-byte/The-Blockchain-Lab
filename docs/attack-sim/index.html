Classroom tool

51% Attack Simulator

Race a private chain against honest miners. Each next block is random. The attacker finds it with probability equal to their hash share.

What you are watching

An attacker spends their hash power on a private chain that starts 1, 2, or 3 blocks behind the public tip. Honest miners keep extending the public chain. The classroom hub follows the longer chain. When the private chain grows longer, the hub switches to it. That switch is a reorganization, and the attack wins.

Every block is a weighted coin flip. The attacker finds the next block with probability equal to their share of the hash power, and an honest miner finds it otherwise. A 30% attacker wins some races. A 70% attacker loses some. This page never picks the winner in advance. Leave the seed blank to use the browser’s Math.random, or enter a seed to replay the same luck.

Each trial uses the lab’s real hub code: tryAddBlock and _selectBestChain in RelayBlockchainState. The longest chain wins, and a tie stays with the chain the hub saw first. The hub also rejects a block whose parent is more than 10 blocks behind the current tip, so a phone that fell asleep cannot flood the class with old work. For an attacker that rule is final. Once their private tip is 11 blocks behind, the next private block is rejected and they cannot catch up. Give-up depth defaults to 11 so a failed trial ends on that wall. A smaller give-up means the attacker quits while the hub would still accept another block. A larger give-up still ends at 11, because the hub will not take a parent more than 10 blocks back.

The clock is simulated. The wait between blocks is random, and the average wait is the block time you set (10 seconds is the classroom default). The time column is that chain clock. This page does not mine on a live class session.

How to read a row

Win means the attacker’s block became the hub’s canonical tip, listed as “Reorg at block N”. Fail means the public tip pulled that many blocks ahead of the private tip. At 11 behind, the next private block would be rejected as a stale parent, so the attacker cannot recover. A row that says Timed out hit the safety cap before either of those. The cap does not choose a winner. Block counts and the clock start when the race starts, after the honest pre-chain is already in place.
