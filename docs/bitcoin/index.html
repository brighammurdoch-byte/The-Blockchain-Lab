Bitcoin classroom

Bitcoin Lab

Same classroom as the main lab: an instructor hub, then nodes that mine and send BTC. Subsidy starts at 50 BTC and halves every 21 blocks (Core is 210,000 — scaled so a class can see a halving).

Instructor

Create a Bitcoin session. Your browser is the hub — share the code or QR. Students join as miners or wallets.

Keep the admin tab open for the whole class period.

Student

Join with the session code (or the shared link / QR). Miners also have a wallet. Wallets watch and send.

What this classroom shows

  • Proof of Work
  • Block subsidy
  • Halving
  • Wallets & transfers
  • Consensus

This is not bitcoind. Students run a Bitcoin-like classroom chain in the browser (50 BTC subsidy, halvings, the same hub/miner/wallet flow as the main lab). It is a teaching twin — not Bitcoin Core.

Main classroom lab · Optional C++-shaped rules editor (solo, not the class mesh)
