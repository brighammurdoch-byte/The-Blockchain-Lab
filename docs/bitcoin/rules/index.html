Bitcoin-like C++ rules

← Back to Bitcoin classroom · solo editor for subsidy / halving experiments. The live class uses the classroom hub instead.

This is not bitcoind. Bitcoin Core is real C++ compiled with clang/gcc. Your browser cannot do that. The editor is trimmed to look like validation.cpp / pow.cpp. On Apply, a translator reads the constants and checks (subsidy, halving interval, MAX_MONEY, empty vin) and feeds them into a JavaScript engine that implements those same Bitcoin rules. Change 50 * COIN and the next coinbase really pays 100. That is the same kind of experiment as editing Core — not the same as merging a PR.

What happens when you click Apply

  1. The page does not compile C++.
  2. A small reader scans this source for Core names: GetBlockSubsidy, nSubsidyHalvingInterval, MAX_MONEY, vin.empty().
  3. Those values become the live JavaScript UTXO engine’s parameters.
  4. The next block you mine uses the new subsidy / checks. This standalone is one browser only — use the Bitcoin classroom for an instructor hub plus miner/wallet nodes.
