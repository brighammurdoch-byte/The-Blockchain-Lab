This is the validation code running on your miner. Modify it to experiment with forks, attacks, or consensus changes!

Key Functions to Modify
validateBlockHash() - Proof-of-Work
What it does:Checks if the block hash has the required number of leading zeros
Experiment:Try changing requiredLeadingZeros: 3to 4 or 2
What happens:
  • 3 zeros: Normal mining difficulty
  • 4 zeros: HARD FORK - incompatible with others
  • 2 zeros: Soft fork - blocks still validate
Educational value:Learn why Proof-of-Work difficulty is critical to blockchain security
validateTransaction() - Double-Spend Prevention
What it does:Verifies that users can't spend coins they don't have
Experiment:Try removing the balance check to allow double-spending
What happens:
  • Remove check: Can send infinite coins ✗
  • Keep check: Transactions validated ✓
Educational value:This is the fundamental security preventing coin duplication
validatePreviousHash() - Chain Integrity
What it does:Ensures each block links to the previous block
Experiment:Try allowing ANY previous hash (remove the check)
What happens:
  • Remove check: Chain breaks into fragments ✗
  • Keep check: Chain stays linked ✓
Educational value:This is the "chain" in "blockchain" - without it, anyone could reorganize history
