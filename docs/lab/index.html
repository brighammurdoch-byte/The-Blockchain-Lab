The Blockchain Lab

Run a live Proof-of-Work network with your class — mine blocks, move coins, and watch consensus form in real time.

Instructor

Create a session. Your browser becomes the hub — share the code or QR with students.

Keep the admin tab open for the whole class period.

Student

Join with a session code (or a shared link / QR). Choose miner or wallet.

What you’ll demonstrate

  • Proof of Work
  • Consensus
  • Transactions
  • 51% attacks
  • Hard forks

Bitcoin classroom — same admin + miner/wallet nodes, with a 50 BTC subsidy and halvings. · Ethereum rules lab — optional Solidity-shaped editor.

Based on Anders Brownworth’s Blockchain Demo. No backend session server required — coordination runs in the browsers. Want to help improve the lab? Contribute on GitHub.
