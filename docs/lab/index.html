About Blockchain Lab

This interactive demonstration shows how blockchains work in a peer-to-peer network. As an instructor, you can create a session and give students a code to join. Students can observe the blockchain or participate in mining blocks.

Key concepts demonstrated:

  • Proof of Work (PoW) mining
  • Block validation and chain integrity
  • Network consensus
  • 51% attack vulnerability
  • Transaction processing

Based on Anders Brownworth's Blockchain Demo
